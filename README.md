# digital-archaeologiat

this is aimed to be interactive retro-terminal mystery where users explore a fictional abandoned research facility through commands, encrypted files, and hidden clues

## Features
- Simulated terminal interface
- Custom command parser
- Fictional files and research logs
- Hidden clues and secret endings
- Responsive interface

## Built With
- HTML
- CSS
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Type `help` to see the available commands.
4. Explore the terminal and uncover the mystery.
